# KomeMaku

![KomeMaku icon](icons/icon128.png)

YouTubeの公開コメントを、動画の上にニコニコ動画風の**流れる弾幕**として表示する、Chrome / Edge向けのManifest V3拡張機能です。

**KomeMakuはYouTube、Google、YCS Continuedの公式製品ではありません。** コメントの閲覧・表示用であり、コメントの投稿はできません。

## 主な機能

- **動画と同期する弾幕**：再生・一時停止・シーク・倍速・タブ切り替え後も動画の再生位置に合わせて表示。本文の `1:20` のような時刻指定は、指定秒数に**文字の先頭が画面中央へ到達する**位置を目指して配置します。
- **コメントの選別**：表示頻度と密度、いいね数の多い順／投稿日時が新しい順、返信の表示・非表示、長い複数行コメントの除外、タイムスタンプ非表示を設定できます。投稿日時を取得できないコメントは「新しい順」で後回しになります。
- **人気コメント**：いいね数上位の一部を画面下端に拡大表示。一定行数以上の人気コメントを通常のスクロール弾幕へ戻すこともできます。
- **見た目の調整**：文字サイズ、画面サイズに応じた自動拡大縮小、行間、フォント、文字色、縁取りの有無・太さ・透明度、流速、色・速度のランダム化に対応します。
- **複数行の衝突回避**：文字幅・行数・行間・縁取りを考慮して配置します。混雑時に限り、1行コメント同士を半行ずらすオプションがあります。
- **描画と性能**：WebGL2（利用できない場合はCanvas 2D）、FPS上限、自動FPS調整、Workerによるコメント配置計算を利用できます。
- **翻訳（任意）**：コメントを選択言語へ翻訳できます。**有効にした場合のみ**翻訳対象のコメント本文をGoogle翻訳サービスへ送信します。非公式エンドポイントのため動作保証はありません。
- **YCS Continued連携**：YCSで追加取得したコメント・返信を読み込み、YCSからエクスポートしたJSONも取り込めます。YouTubeのライブチャットにも対応します。

## インストール

1. [GitHub Actionsのビルド一覧](https://github.com/Sanowo0390/KomeMaku/actions/workflows/build.yml) から成功した最新のビルドを開き、成果物 **`KomeMaku-v...`** を取得します（GitHubへのログインが必要な場合があります）。
2. ダウンロードしたZIPを**1回だけ解凍**します。中にある `KomeMaku` フォルダーの直下に `manifest.json` があることを確認してください。
3. Chromeの `chrome://extensions` またはEdgeの `edge://extensions` で「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から `KomeMaku` フォルダーを選びます。
5. 既にYouTubeを開いている場合はタブを再読み込みします。旧版を別の拡張機能として読み込んだ場合は、二重表示を避けるため旧版を無効化してください。

Actionsの成果物は、**ZIPの中に別のZIPが入っていない構造**です。

## 設定方法

拡張機能アイコンをクリックすると、設定をカテゴリー別に開閉できるポップアップが表示されます。「すべての設定を専用ページで開く」を押すと、検索や初期化に対応した設定センターが別タブで開きます。YouTubeプレイヤー内の弾幕設定パネルからも一部の設定を変更できます。

設定はブラウザー内の `chrome.storage.local` に保存され、各画面で共通です。専用設定ページは拡張機能内のページであり、外部サイトのアカウント登録は不要です。

PCにインストール済みのフォントは、対応するChrome/Edge環境で、専用設定ページの「PCのフォント一覧を読み込む」から選択できます。フォント一覧へのアクセスはユーザー操作による許可が必要で、フォントファイルは収集しません。非対応の場合もプリセットのフォント設定を使用できます。

## YCS Continuedとの連携

[YCS Continued](https://chromewebstore.google.com/detail/mfobjniokjbcldieppimekoibpocahed) を別途インストールし、YouTube動画ページでYCSの「Load all」を実行すると、追加取得されたコメントをKomeMakuが取り込みます。

既にYCS側で読み込み済みのコメントについて通信が再発生しない場合は、YCSからJSONを書き出し、KomeMakuのポップアップから読み込んでください。**JSONの動画IDは現在の動画と一致する必要があります。** 対象は取得できた公開コメントのみで、削除済み・非公開コメントを復元することはできません。

## 動作とプライバシーに関する注意

- 動画の再生時刻が書かれていない通常コメントは、動画全体へ分散配置されます。動画長・混雑度・速度制限によっては一部が表示対象外になります。「無制限」も全件表示を保証するものではありません。
- コメント取得にはYouTubeのページ・内部APIの構造を利用するため、YouTubeやYCSの仕様変更で取得が失敗する可能性があります。YouTube・YCS・GPUのすべての組み合わせで実動作を保証するものではありません。
- 翻訳を有効にした場合のみ、翻訳が必要な**コメント本文**を外部サービスへ送信します。翻訳失敗時は原文を表示します。
- コメントは動画タブ内のメモリ上で処理し、大量取得時にはメモリ使用量や再計算負荷が増加します。別動画へ移動すると取得データは切り替わります。
- YouTube上のほかの拡張機能と通信フックが競合する場合があります。

## 開発とテスト

このリポジトリの `tests/` にNode.jsで実行できるテストがあります。

```bash
for file in tests/*.cjs; do node "$file"; done
```

GitHub ActionsはJavaScriptの構文・各テストを検証し、インストール用成果物を生成します。**テスト成功は実際のYouTube/YCSでの完全な動作保証ではありません。**

アイコンを更新する場合、原本の `icons/icon.svg` と `icons/icon-small.svg` を編集し、以下のコマンドで16/32/48/128pxのPNGを生成して一緒にコミットしてください。

```bash
python -m pip install "CairoSVG>=2.7,<3" "Pillow>=10,<13"
python scripts/render-icons.py
```

### 主なファイル

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の権限・読み込み設定・バージョン |
| `content.js` / `player.css` | プレイヤー操作・描画・設定の反映 |
| `logic.js` / `scheduler-worker.js` / `scheduler-host.*` | 選別・レーン計算・Worker処理 |
| `renderer-webgl.js` | WebGL2描画 |
| `bridge.js` / `ycs-bridge.js` / `ycs-parser.js` | YouTube・YCSコメントの取得と解析 |
| `popup.*` / `options.*` / `settings-groups.js` | カテゴリー別設定UI |
| `i18n.js` | 日本語・英語・簡体字／繁体字のUI |
| `background.js` / `live-chat.js` | タブ間通信・ライブチャット |
| `icons/` / `scripts/render-icons.py` | アイコン原本・生成処理 |
