# KomeMaku v1.5.0 — YouTube Comment Danmaku

YouTube動画の公開コメントを、動画プレイヤー上のスクロール弾幕として表示する **Chrome / Edge 向け Manifest V3 拡張機能**です。Dmooji、YouTube、YCS Continuedの公式製品ではありません。コメント表示に特化しており、コメント投稿や外部サーバーへのアップロードは行いません。

## v1.5.0: 追加した機能

| 機能 | 状態と動作 |
|---|---|
| YouTubeコメントの自動取得 | 動画を開くと即座に取得開始。初期取得は内蔵の軽量Innertube取得（最大180件）、画面のコメント領域からも補完 |
| 動画上への弾幕表示 | Canvasでコメントを右から左へ表示。動画再生時刻に同期 |
| 日本語・英語・簡体字中国語・繁体字中国語 | ポップアップとプレイヤー内の設定UIで4言語対応。ブラウザー言語による自動選択も可能 |
| 先読み | 動画表示直後に取得開始。弾幕の表示をオンにする前から読み込み可能（ユーザー操作不要） |
| プレイヤー操作バーに統合 | YouTubeの右側コントロールバーへ弾幕アイコンを追加。アイコンから設定パネルを開いて表示切替・各設定を変更できる。バーが見つからない場合はプレイヤー内に小さな代替ボタンを表示 |
| レイアウトを変えない表示 | 動画プレイヤーの上に絶対配置したCanvasと設定パネルを重ね、動画のレイアウト寸法を変更しない |
| 色・サイズ・速度の調整 | 単色HEXカラー、文字サイズ、流速、表示頻度、不透明度、速度の変更を反映 |
| ランダムな色・速度 | 複数色のパレットと、基本速度の0.75〜1.25倍をコメントごとに適用できる。動画のシーク・タブ復帰で見た目が変わらないようコメントIDから固定的に算出 |
| 同一ページ内の動画切替 | YouTubeのSPA遷移（ホーム→動画、関連動画、Shorts等）を検知して、動画ID・コメントを切り替えて自動取得・再描画 |

### 継続している機能

- **YCS Continued連携**：YCSの「Load all」中のYouTubeコメント通信から親コメント・返信・ネスト返信を取り込む。YCSのJSONエクスポートも読み込み可能。
- **いいね数が少ないコメントから間引く**：動画時間・表示頻度で表示できる件数を計算し、表示対象をいいね数の多い順に選別。YCSから後で高評価のコメントが来た場合は再選別。
- **衝突しないレーン配置**：文字幅とコメントごとの速度差を考慮して、同じレーンで重なったり追い越したりしないよう表示時刻を調整。配置し切れないコメントは除外。
- **再生時刻への同期**：シーク、巻き戻し、早送り、倍速、一時停止、タブを離れて戻った後も動画時刻から描画位置を復元。
- **終了時の見切れ防止**：動画終了の0.6秒前までに流れ切れる時刻・速度で配置。
- **ライブチャット**：YouTubeのライブチャットiframeから届くメッセージを、その場で動画上に表示。

## ダウンロード・インストール

GitHubの **Actions → Build KomeMaku → 最新の成功実行 → Artifacts → `KomeMaku-v1.5.0`** からZIPを取得できます。デベロッパーモードで読み込むときはZIPを展開してください。

## インストール

1. `KomeMaku-v1.5.0.zip` を解凍します。
2. Chromeなら `chrome://extensions`、Edgeなら `edge://extensions` を開きます。
3. 「デベロッパーモード」をオンにし、「パッケージ化されていない拡張機能を読み込む」で **`manifest.json` が入った `KomeMaku` フォルダー**を選びます。
4. 以前のバージョンをすでにインストール済みなら、旧版を削除・無効化してください（両方有効だと弾幕が二重になります）。
5. インストール後、すでに開いていたYouTubeタブは **1回だけ再読み込み**してください。以降のYouTube内画面遷移は自動対応します。

## 設定

動画プレイヤー右下のコントロールバーに追加される弾幕アイコンをクリックすると、設定パネルを開けます。表示のオン/オフ、色、サイズ、流速、表示頻度、色と速度のランダム化、UI言語を変更できます。YouTubeの画面を占有する別ページを開く必要はありません。従来の拡張機能アイコンからのポップアップも使用可能で、**設定は共通**です。

ランダム速度は**再生速度そのもの**を変更するわけではありません。コメントごとの横断速度に変化をつけるだけです。ランダムでもレーン衝突防止は働きます。

## YCS Continuedとの連携

- [YCS Continued](https://chromewebstore.google.com/detail/mfobjniokjbcldieppimekoibpocahed)を別途インストール。
- YouTube動画ページでYCSの「Load all」を実行すると、YCSが追加取得したコメントをKomeMaku側でも読み取れます。
- YCSで過去に読み込み済みで通信が発生しないコメントは、YCSからJSON形式で書き出し、KomeMakuのポップアップでJSONを選んで取り込んでください。
- JSONから取り込むときは**動画IDが一致している必要**があります。コメントはメモリ上に保持し、画面の動画が切り替われば保持データも入れ替えます。

**全件に関する制限：** YCS自身が取得できた公開コメントと返信のみが対象で、削除済み・閲覧権限のないコメントは復元できません。また、1万件を数分の動画で全件読める速度で流すことは難しいため、実表示数には上限があります。いいね数が少ないコメントから間引く設定は継続しています。

## 技術的な注意・プライバシー

- 投稿時刻しかないYouTubeコメントは動画中の発言時刻を示しません。本文にタイムスタンプがあるものは可能な範囲でその位置へ配置し、通常コメントは動画全体へ分散します。
- YouTubeの内部API・DOMとプレイヤーのクラス名は予告なく変更されます。その場合、先読み、YCS連携、操作ボタンが動作しないことがあります。YCSの拡張機能専用ストレージを直接読むことはできません。
- 「先読み」はバックグラウンドでコメント収集を続けるクラウド機能ではなく、**YouTube動画タブが開かれた時点からコメントを取得する**機能です。通信やコメントの量によっては表示に時間がかかる場合があります。
- サーバーへの外部送信やユーザーのコメント投稿機能はありません。YCSのJSONはポップアップ内で読み込み、現在のYouTubeタブに小分けで渡します。
- 動画を切り替えるとメモリ上のコメントは破棄されます。大量コメントを取り込む場合、ブラウザーのメモリ消費とスケジュール再計算が増えます。
- 他の拡張機能と同じページ上の`fetch`をラップする仕組みは干渉する可能性があります。

## 検証

`node tests/test.cjs` など、`tests/`内の `.cjs` ファイルをNode.jsで実行します。

- v1.3.0からのコメント解析・YCS連携・レーン衝突・シーク・タブ切替などの既存テストを維持。
- v1.5.0追加テスト：4言語、ランダムカラーと速度の安定性、各速度でのレーン衝突防止、YouTubeプレイヤー内ボタン/設定パネル操作と設定同期。
- **YouTubeの実際の本番サイト・YCS本体を併用したブラウザー動作検証は未実施です。** 自動テスト成功と実環境の互換性は区別してください。

## ファイル構成

- `manifest.json` — Manifest V3、全YouTubeページの初期化
- `bridge.js` — 最初のコメントを自動取得
- `ycs-bridge.js` / `ycs-parser.js` — YCSコメント通信とJSONの互換解析
- `logic.js` — いいね優先、固定ランダム色・速度、表示スケジュールと衝突回避
- `content.js` / `player.css` — Canvas描画、プレイヤー内操作ボタンと設定パネル
- `i18n.js` — 日本語・英語・簡体字中国語・繁体字中国語の翻訳
- `popup.html` / `popup.js` / `popup.css` — ポップアップ設定、YCS JSON取り込み
- `live-chat.js` / `background.js` — ライブチャット受信と転送
- `tests/` — ソース版のみ。Node.jsユニット・描画モックテスト

YCS Continuedのデータ形式は [pc035860/YCS-cont](https://github.com/pc035860/YCS-cont) を参照しました。YCSのソースコードをコピーしていません。

## v1.5.0 — 高密度動画向け最適化

- YCSのLoad allでコメントが増加した場合も、すでに再生が始まった弾幕の表示時刻・レーンを固定。まだ表示していない時間帯のみ再計算。
- 表示予定の再計算をまとめて実行し、描画を最大30fpsに制限。背景タブ・一時停止中は同じフレームを重複描画しません。
- コメント文字を小さなCanvasスプライトとして再利用（上限20 MiB / 130件）。DPIとバックバッファ面積にも上限を設定。
- 返信コメント非表示（YCSの投稿・返信属性に基づく）。未特定返信には完全な判定は保証されません。
- 改行表示 ON/OFF と「N行以上のコメントを非表示」（0は無効）。改行OFFでも元テキストの改行数で判定。
- いいね数の多い表示対象コメントの上位0〜30%を中央に1.5倍、約3.8秒表示。いいね数0件は対象外。

### 制限事項

コメントはYouTubeの通常コメントで、再生秒数を持たないものがあります。これらは動画全体に割り振ります。YCSの読み込み前のまだ取得していないコメントは表示できません。読み込みが長時間続く場合、今後表示する予定は更新されますが、再生済みの表示予定は保持します。キャンバスへの描画とJSONの解析・YCS側の読み込みコストは環境によって変動します。
