# KomeMaku v1.8.6 — YouTube Comment Danmaku

## v1.8.6 — PCフォント選択・縁取り不透明度・プレイヤー連動の文字拡大縮小

- **PCのインストール済みフォント**：専用設定ページの「PCのフォント一覧を読み込む」をクリックし、Local Font Access APIの権限を許可すると、実際にインストールされているフォントファミリーから選べます。対応するデスクトップ版Chrome/Edgeのみ。拒否・非対応時は5種類のプリセットが利用できます。読み込みはユーザーが操作した場合だけ行い、選んだフォント名のみ保存します（フォントファイルは送信・保存しません）。
- **縁取りの不透明度**：黒い縁取りだけの不透明度を0～100%で指定。初期値86%、縁取りの太さとオン/オフは維持。Canvas 2D・WebGL2のキャッシュキーに含めます。
- **プレイヤー連動の文字サイズ**：自動拡大縮小をオン（初期値）にすると、960×540で100%、幅と高さの両方を考慮して65～250%の範囲で文字サイズを調整します。オフなら設定したpxで固定します。シアター・全画面・画面サイズ変更時はレーン配置とWorkerを再計算します。


## v1.8.5 — 複数行の衝突回避・フォント・縁取り設定

- **複数行の配置判定を実際の文字描画高さに合わせました。** 行数・行間・自動縮小後の文字サイズ・縁取り幅を含む矩形が重なる場合は、別レーン・後続時刻を優先します。混雑時の半行重なりは1行同士だけに限定し、複数行を保護します。
- **フォントの選択**：標準 / ゴシック / 明朝 / 丸ゴシック / 等幅。端末にインストールされた字体のフォールバックを利用し、フォントファイルや外部リソースはダウンロードしません。
- **縁取り設定**：オン・オフおよび太さ25〜250%（初期設定100%、従来と同じ）。Canvas 2D・WebGL2の両方で描画に反映します。
- **設定画面との同期**：専用設定ページ・ポップアップ・動画プレイヤー内から変更可能で、Worker計測・キャッシュ・レイアウトを更新します。
- **注意**：ニコニコ風の半行ずらしをオンにすると、混雑時の1行コメント同士には意図的な部分重なりが発生します。複数行のコメントにはこの例外を適用しません。


## v1.8.4 — タイムスタンプの先頭位置を「中央」へ変更

- `1:20` のような時刻を含むスクロールコメントは、**指定された80秒に文字の先頭が動画の中央へ到達**するように前倒し表示します。v1.8.3の「左端」から変更しました。
- 現在の画面幅・文字幅・速度に合わせて前倒し量を計算します。冒頭の時刻指定では、再生開始前から流れていた位置として表示できます。
- 下端に固定される人気コメントは、これまでどおり指定時刻に表示を開始します。混雑時の衝突回避や動画終端の条件によっては、スクロールコメントの位置がわずかにずれる場合があります。
- WorkerとCanvas 2Dフォールバックのどちらでも同じ位置計算を使用します。


## v1.8.3 — タイムスタンプの先頭位置を動画時刻に同期

- コメント内の `1:20` などのタイムスタンプは、**指定した1分20秒にスクロール文字の先頭（左端）が動画の左端へ到達する**よう、右端から左端までの走行時間を差し引いて早めに開始します。
- スクロール速度、表示幅、コメント幅から正確な前倒し量を求め、固定的な秒数は使用しません。0:00など冒頭の指定では、再生開始時点から既に画面上を流れている配置として扱います。
- 人気コメントの下端固定表示は前倒しせず、指定した時刻に表示します。混雑時にはレーン衝突を避けるため、希望時刻から多少ずれる場合があります。
- WorkerとCanvas 2Dフォールバックの両方に対応し、シーク後も動画再生時刻に一致します。


## v1.8.2 — 行間調整

- 行間を **70〜200%** の範囲で変更できます（初期値 **100%**）。
- 改行コメントの行送り、通常コメントのレーン間隔、画面下端の人気コメントの積み重ね間隔に適用されます。
- Canvas 2D と WebGL2、メインスレッド計算と Worker 計算で同じ設定を使い、設定変更は自動保存・即時再配置されます。
- 70%のように狭めたときは、文字が視覚的に重なることがあります。


YouTube動画の公開コメントを、動画プレイヤー上のスクロール弾幕として表示する **Chrome / Edge 向け Manifest V3 拡張機能**です。Dmooji、YouTube、YCS Continuedの公式製品ではありません。コメント表示に特化しています。翻訳機能をオンにした場合に限り、選択したコメント本文を外部の翻訳サービスへ送信します。

## v1.8.1 — 監査指摘の不具合修正

- **Worker巻き戻し**：Workerが返す時間範囲と実際のコメントデータが一致するようにし、シーク完了時には表示データを再要求します。過去コメントを含む全体の配置計画はWorker内部に保持し、メインスレッドには必要な時間範囲だけを転送します。
- **YCS追加読み込み**：新しいコメントの取得後にも、既に計画した過去コメントを消さずに保持します。後から届いた過去時刻のコメントも可能な範囲で配置します。
- **翻訳反映**：表示開始済みのコメントは時刻・レーンを維持しながら翻訳後のテキストへ更新します。翻訳に伴う文字幅の変化では一時的な近接表示が起こる可能性があります。
- **人気コメント・優先度**：Worker初回計算で冒頭の人気コメントを落とさず、同時刻の競合時は「新しい順」設定を尊重します。
- **返信と取得データ**：明示タイムスタンプ付き返信の時刻を保持し、YCS JSONのURL由来の親コメントIDを子へ引き継ぎます。DOM取得の改行・長文、内蔵APIの投稿日時・返信属性も保持します。同じ相対日時ラベルの再読込では投稿日時を更新しません。
- **WebGL2**：アトラスがいっぱいになっても文字をレイアウトから欠落させず、確保できない場合はCanvas 2Dへ切り替えます。
- **FPS**：60Hz画面の24・45FPSなどで値が意図せず大きく下がる時間切り捨てを修正しました。
- **診断表示**：API取得失敗・継続トークン不足・0件を、ポップアップで先読み中と区別します。
- **回帰テスト**：巻き戻し、増分取得、翻訳、コメント優先度、返信時刻、FPS、WebGL2キャッシュなどの回帰テストを追加しています。

実際のYouTube・YCS・GPUでの統合動作や、パフォーマンス改善の定量評価は未実施です。既存のUIと機能は維持しています。

## v1.8.0 — 削減優先順位・専用設定ページ

- **表示削減の優先順位**を「人気順（いいね数）」または「新しい順（投稿日時）」から選択できます。デフォルトは従来と同じ人気順です。中央固定の人気コメント選別は引き続き「いいね数」を使用します。
- 「新しい順」は取得済みコメントの**投稿日時**で判定します。動画内タイムスタンプやYCSの取得順は投稿日時の代わりに使いません。投稿日時がないコメントは末尾扱いになり、取得元の情報量によって選別精度が異なります。
- **専用設定ページ**（`options.html`）を追加。拡張機能のポップアップにある「すべての設定を専用ページで開く」、YouTubeの弾幕パネル、Chrome/Edgeの拡張機能管理画面から開けます。全項目をカテゴリ別に整理し、検索・即時保存・リセットに対応。
- 設定は `chrome.storage.local` で共通保存し、ポップアップ・動画プレイヤー・専用ページ間で同期します。
- 独立した外部サイトや新たなアカウントは不要です。Chrome/Edgeにインストールした拡張機能の内部ページです。

## v1.7.2 — 人気コメントの表示切替・除外を軽減

- **「何行以上の人気コメントを通常表示にする」** を追加。0で無効、1〜10行以上を指定可能。原文の改行数で判定するため、改行表示OFFでも複数行の人気コメントを流せます。
- 人気コメントを画面下端に配置できない場合（幅92%超、拡大後の高さ、下端の混雑、動画終了直前）は、**除外ではなく通常スクロール表示に再投入**します。通常レーンに空きがない場合などには除外される可能性があります。
- Workerとメインスレッド双方のスケジューラーに同じ処理を実装し、ポップアップとプレイヤー内の設定を同期します。変更時の表示対象件数も再計算します。
- 人気コメントの上位割合は従来と同じで、いいね0件は中央表示の候補に含めません。

## v1.7.1 — WebGL2の文字上下反転を修正

- WebGL2の文字テクスチャをアップロードする際の上下反転フラグを修正しました。Canvas 2Dの表示には変更ありません。
- 上下反転・左右反転の再発防止テストを追加しました。
- **描画エンジンがWebGL2のとき文字が上下逆に見えた場合は、この修正版に更新してYouTubeタブを再読み込みしてください。**

## v1.7.0 — 描画エンジン刷新・FPS設定

- **描画エンジン**：`自動（WebGL2優先） / WebGL2 / Canvas 2D` を選択できます。WebGL2での描画が初期化できない場合は自動的にCanvas 2Dへフォールバックします。
- **WebGL2文字アトラス**：文字画像を単色のグリフとして再利用し、GPU側で着色して1回の描画バッチへまとめます。コメントのランダム色でも文字画像を作り直しません。2ページの2048×2048アトラスを上限にし、ページ単位で入れ替えます。
- **別スレッドのスケジューラー**：拡張機能内部のWorkerでコメントの選別・テキスト幅計測（OffscreenCanvas）・レーン計算を行います。YCSの新規コメントは差分だけ送信し、プレイヤーには現在の再生位置付近の計画のみ渡します。シーク時は再生位置に応じて必要な区間を再取得します。Workerに問題があれば従来のメインスレッド側の計算に戻ります。
- **描画FPS**：`自動 / 15 / 24 / 30 / 45 / 60 / 120 FPS`。自動は描画時間を参考に15・24・30・60 FPSから選び、背景タブや停止中は不要な再描画を避けます。実際のGPU速度は環境依存で、上限FPSを必ず達成するわけではありません。
- **人気コメントの配置処理を最適化**：過去の全候補を毎回走査する処理を、表示中候補だけを保持する方式へ変更しました。
- YCS連携、いいね数選別、返信の近接表示、複数行中央揃え、翻訳、衝突防止の設定は従来のままです。

**注意:** 実際のYouTubeとYCS本体を使うブラウザー検証は未実施です。この環境のChromiumではページアクセスが管理者設定で遮断されたため、WebGL2およびWorkerの単体テストで検証しています。WebGL2のほうが必ず速いとは限らず、端末ごとの測定が必要です。 

## 主な機能

| 機能 | 状態と動作 |
|---|---|
| YouTubeコメントの自動取得 | 動画を開くと即座に取得開始。初期取得は内蔵の軽量Innertube取得（最大180件）、画面のコメント領域からも補完 |
| 動画上への弾幕表示 | WebGL2優先（使えない場合Canvas 2D）で右から左へ表示。動画再生時刻に同期 |
| 日本語・英語・簡体字中国語・繁体字中国語 | ポップアップとプレイヤー内の設定UIで4言語対応。ブラウザー言語による自動選択も可能 |
| 先読み | 動画表示直後に取得開始。弾幕の表示をオンにする前から読み込み可能（ユーザー操作不要） |
| プレイヤー操作バーに統合 | YouTubeの右側コントロールバーへ弾幕アイコンを追加。アイコンから設定パネルを開いて表示切替・各設定を変更できる。バーが見つからない場合はプレイヤー内に小さな代替ボタンを表示 |
| レイアウトを変えない表示 | 動画プレイヤーの上に絶対配置したCanvasと設定パネルを重ね、動画のレイアウト寸法を変更しない |
| 色・サイズ・速度の調整 | 単色HEXカラー、文字サイズ、流速、表示頻度、不透明度、速度の変更を反映 |
| ランダムな色・速度 | 複数色のパレットと、基本速度の0.75〜1.25倍をコメントごとに適用できる。動画のシーク・タブ復帰で見た目が変わらないようコメントIDから固定的に算出 |
| 同一ページ内の動画切替 | YouTubeのSPA遷移（ホーム→動画、関連動画、Shorts等）を検知して、動画ID・コメントを切り替えて自動取得・再描画 |

### 継続している機能

- **YCS Continued連携**：YCSの「Load all」中のYouTubeコメント通信から親コメント・返信・ネスト返信を取り込む。YCSのJSONエクスポートも読み込み可能。
- **いいね数が少ないコメントから間引く**：動画時間・表示頻度で表示できる件数を計算し、表示対象をいいね数の多い順に選別。YCSから後で高評価のコメントが来た場合は再選別。
- **衝突しないレーン配置**：文字幅とコメントごとの速度差を考慮して、同じレーンで重なったり追い越したりしないよう表示時刻を調整。配置し切れないコメントは除外。
- **再生時刻への同期**：シーク、巻き戻し、早送り、倍速、一時停止、タブを離れて戻った後も動画時刻から描画位置を復元。
- **終了時の見切れ防止**：動画終了の0.6秒前までに流れ切れる時刻・速度で配置。
- **ライブチャット**：YouTubeのライブチャットiframeから届くメッセージを、その場で動画上に表示。

## ダウンロード・インストール

このZIPを展開して、デベロッパーモードから `KomeMaku` フォルダーを読み込んでください。GitHub Actionsへの反映後はActionsの成果物からも取得できます。

## インストール

1. `KomeMaku-v1.8.6.zip` を解凍します。
2. Chromeなら `chrome://extensions`、Edgeなら `edge://extensions` を開きます。
3. 「デベロッパーモード」をオンにし、「パッケージ化されていない拡張機能を読み込む」で **`manifest.json` が入った `KomeMaku` フォルダー**を選びます。
4. 以前のバージョンをすでにインストール済みなら、旧版を削除・無効化してください（両方有効だと弾幕が二重になります）。
5. インストール後、すでに開いていたYouTubeタブは **1回だけ再読み込み**してください。以降のYouTube内画面遷移は自動対応します。

## 設定

動画プレイヤー右下のコントロールバーに追加される弾幕アイコンをクリックすると、設定パネルを開けます。表示のオン/オフ、色、サイズ、流速、表示頻度、色と速度のランダム化、UI言語を変更できます。YouTubeの画面を占有する別ページを開く必要はありません。従来の拡張機能アイコンからのポップアップも使用可能で、**設定は共通**です。

ランダム速度は**再生速度そのもの**を変更するわけではありません。コメントごとの横断速度に変化をつけるだけです。ランダムでもレーン衝突防止は働きます。

## YCS Continuedとの連携

- [YCS Continued](https://chromewebstore.google.com/detail/mfobjniokjbcldieppimekoibpocahed)を別途インストール。
- YouTube動画ページでYCSの「Load all」を実行すると、YCSが追加取得したコメントをKomeMaku側でも読み取れます。
- YCSで過去に読み込み済みで通信が発生しないコメントは、YCSからJSON形式で書き出し、KomeMakuのポップアップでJSONを選んで取り込んでください。
- JSONから取り込むときは**動画IDが一致している必要**があります。コメントはメモリ上に保持し、画面の動画が切り替われば保持データも入れ替えます。

**全件に関する制限：** YCS自身が取得できた公開コメントと返信のみが対象で、削除済み・閲覧権限のないコメントは復元できません。また、1万件を数分の動画で全件読める速度で流すことは難しいため、実表示数には上限があります。いいね数が少ないコメントから間引く設定は継続しています。

## 技術的な注意・プライバシー

- 投稿時刻しかないYouTubeコメントは動画中の発言時刻を示しません。本文にタイムスタンプがあるものは可能な範囲でその位置へ配置し、通常コメントは動画全体へ分散します。
- YouTubeの内部API・DOMとプレイヤーのクラス名は予告なく変更されます。その場合、先読み、YCS連携、操作ボタンが動作しないことがあります。YCSの拡張機能専用ストレージを直接読むことはできません。
- 「先読み」はバックグラウンドでコメント収集を続けるクラウド機能ではなく、**YouTube動画タブが開かれた時点からコメントを取得する**機能です。通信やコメントの量によっては表示に時間がかかる場合があります。
- **翻訳をオンにした場合だけ、翻訳対象コメントの本文をGoogleの翻訳サービスに送信します。** この通信は公式APIではなく、応答仕様の変更・429制限などで動作しなくなる可能性があります。翻訳失敗時は原文のまま表示します。翻訳オフなら翻訳用通信は行いません。コメント投稿機能はありません。YCSのJSONはポップアップ内で読み込み、現在のYouTubeタブに小分けで渡します。
- 動画を切り替えるとメモリ上のコメントは破棄されます。大量コメントを取り込む場合、ブラウザーのメモリ消費とスケジュール再計算が増えます。
- 他の拡張機能と同じページ上の`fetch`をラップする仕組みは干渉する可能性があります。

## ファイル構成

- `manifest.json` — Manifest V3、全YouTubeページの初期化
- `bridge.js` — 最初のコメントを自動取得
- `ycs-bridge.js` / `ycs-parser.js` — YCSコメント通信とJSONの互換解析
- `logic.js` — いいね優先、固定ランダム色・速度、表示スケジュールと衝突回避
- `content.js` / `player.css` — 描画ルーティング、プレイヤー内操作ボタンと設定パネル
- `renderer-webgl.js` — GPU文字アトラス、色・位置をまとめてWebGL2描画
- `scheduler-worker.js` / `scheduler-host.*` — Worker/OffscreenCanvasを使ったコメント配置と時間範囲ごとの転送
- `i18n.js` — 日本語・英語・簡体字中国語・繁体字中国語の翻訳
- `popup.html` / `popup.js` / `popup.css` — ポップアップ設定、YCS JSON取り込み
- `live-chat.js` / `background.js` — ライブチャット受信と転送
- `tests/` — ソース版のみ。Node.jsユニット・描画モックテスト

YCS Continuedのデータ形式は [pc035860/YCS-cont](https://github.com/pc035860/YCS-cont) を参照しました。YCSのソースコードをコピーしていません。

## v1.6.1 — 高密度動画向け最適化

- YCSのLoad allでコメントが増加した場合も、すでに再生が始まった弾幕の表示時刻・レーンを固定。まだ表示していない時間帯のみ再計算。
- 表示予定の再計算をまとめて実行し、描画を30fpsを初期の目安として制限。背景タブ・一時停止中は同じフレームを重複描画しません。
- コメント文字を小さなCanvasスプライトとして再利用（上限20 MiB / 130件）。DPIとバックバッファ面積にも上限を設定。
- 返信コメント非表示（YCSの投稿・返信属性に基づく）。未特定返信には完全な判定は保証されません。
- 改行表示 ON/OFF と「N行以上のコメントを非表示」（0は無効）。改行OFFでも元テキストの改行数で判定。
- いいね数の多い表示対象コメントの上位0〜30%を下端に1.5倍、約3.8秒表示。いいね数0件は対象外。

### 制限事項

コメントはYouTubeの通常コメントで、再生秒数を持たないものがあります。これらは動画全体に割り振ります。YCSの読み込み前のまだ取得していないコメントは表示できません。読み込みが長時間続く場合、今後表示する予定は更新されますが、再生済みの表示予定は保持します。キャンバスへの描画とJSONの解析・YCS側の読み込みコストは環境によって変動します。

## v1.6.1: 翻訳・無制限・ニコニコ風の半行重ね

- **翻訳（初期値OFF）**: 翻訳先を日本語・英語・中国語（簡体/繁体）・韓国語・スペイン語・フランス語・ドイツ語から選択。表示中・今後20秒に表示されるコメントのみ最大2件ずつ、Google翻訳の非公式エンドポイントへ送信。外部送信に同意できる場合のみオンにしてください。失敗時は原文のまま表示し、スケジュールとUIの動作を妨げません。非公式サービスのため稼働保証はありません。
- **表示頻度「無制限」**: スライダーの11番目（10/10の次）。コメント件数の事前制限を撤廃。動画の終了時刻と同一レーン上の衝突制約による表示除外は残るため、全コメントを必ず表示する設定ではありません。
- **自動縮小（初期値ON）**: 改行を維持する設定で、3行以上のコメントが増えた場合、行数・プレイヤー高に応じて個別のフォントサイズを下げます（下限12px）。1〜2行のコメントや通常の設定サイズは維持。
- **混雑時に半行ずらす（初期値ON）**: まず普通の1行間隔で配置し、全通常レーンが混雑しているときだけ半行ずれたレーンを追加利用します。半行の行は既存の行と縦方向に重なることがありますが、同じ行内の追い越しは防ぎます。重ねたくない場合はOFF。
- **人気コメントの下端表示**: プレイヤーの下端まで寄せて表示します。複数行は各行を中央揃えにし、ほかの人気コメントと同時に表示する場合は下から上へ積み重ねます。
- **親コメントと返信**: YCS JSONに親IDが含まれる場合は取り込み、親の近い時刻・レーンに返信を配置します。ただし重なりや終端制約により必ず隣り合う保証はありません。

### 負荷と制約

- 無制限＋半行重ねで数万件のコメントを表示する場合、メモリ・描画コストは増えます。低密度や小さな文字サイズと併用してください。
- 翻訳はリアルタイムの優先表示であり、YCSで読み込んだ全件を一括翻訳するものではありません。翻訳の順序により一部は原文のまま表示されます。
- 投稿者名、アカウント情報、閲覧履歴は翻訳リクエストのパラメーターに含めません。ただしコメント本文自体にそれらが書かれている可能性はあります。
- ユーザー操作が必要なChrome拡張機能のインストールを前提とし、YouTube上の手動動作検証は未実施です。

## v1.6.2: 表示・翻訳・設定同期の修正

- **混雑したときだけ半行配置**：最初は従来どおり隣接する通常行が重ならないように表示します。すべての通常行が埋まったとき、半行ずれた予備行を使い始めます。予備行は通常行と縦方向に一部重なる「ニコニコ動画風」の混雑時フォールバックです。
- **人気コメントを最下端へ**：下側に約13%あった余白を撤廃。本文が複数行でも各行を中央揃えにして、下端を基準に描画します。同時に複数件を表示でき、必要に応じて下から順に積み上げます。画面の高さに収まらない場合は省略されます。
- **翻訳の持続**：動画切り替え・翻訳ON/OFF・翻訳先言語変更時に、その動画の未完了処理だけをリセットします。前の動画の通信が長引いても次の動画で翻訳が停止しないようにしました。失敗時は最大3回まで間隔をあけて再試行します。
- **タイムスタンプを非表示**：`タイムスタンプを非表示` オプションを追加（初期値OFF）。例えば `0:35` や `1:02:20` をコメント本文から消します。表示タイミングは元のコメント本文を使うため変わりません。時刻以外のコメント本文は残ります。
- **設定変更時の件数表示を即時反映**：表示頻度や返信非表示、行数制限などの変更で表示対象・除外件数を再計算したら、ポップアップを閉じることなく表示件数が更新されます。動画を別タブで開いていても、アクティブな対象タブからの通知のみを表示します。

**補足**：下端の人気コメントは動画のシークバーや字幕と重なる可能性があります。表示できるコメント数は動画長・流速・画面の大きさにも依存します。実際のYouTube/YCS併用動作の手動確認は未実施です。
